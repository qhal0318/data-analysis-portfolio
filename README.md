# 📊 데이터 분석 포트폴리오

## 🎯 프로젝트 소개

데이터 기반 의사결정으로 비즈니스 임팩트를 만드는 데이터 분석가 포트폴리오입니다.

### 주요 프로젝트

1. **📊 IveKorea 광고 어뷰징 탐지**
   - 98.86% 광고 사기 감소
   - 17개 규칙 + 머신러닝 기반 탐지 시스템

2. **🔍 Picketing 크리에이터 분석**
   - 분석 시간 96% 단축 (8시간 → 3분)
   - Instagram/YouTube API 자동화

3. **💳 InfinityBank 금융 마케팅**
   - 리볼빙 최적 타겟 46.5% 선별
   - KMeans 클러스터링 기반 고객 세분화

## 🛠 기술 스택

- **언어**: Python
- **라이브러리**: Pandas, NumPy, Scikit-learn
- **시각화**: Streamlit, Tableau, Plotly
- **API**: Instagram Graph API, YouTube Data API
